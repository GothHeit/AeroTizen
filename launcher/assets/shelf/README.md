# Top Shelf images (Cinema layout)

Put your own JPEG, PNG or WebP images here (1920×1080 works best) and rebuild.
The Cinema layout shows them behind the top row of apps.

- Name a file after an app to give that app its own image, for example `netflix.jpg`,
  `youtube.jpg` or `moonroom.jpg` (lowercase app name, letters and digits only).
- Other files are shared: each app without its own image gets one of them.
- While this folder has no images, the launcher's weather scenes are used.

Keep images under about 500 KB each; the TV decodes them on a modest chip.
